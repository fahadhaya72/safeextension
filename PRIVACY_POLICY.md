# Privacy Policy - SafeExtension Browser Extension

**Last Updated:** April 2026  
**Effective Date:** April 2026

## 📋 Overview

SafeExtension is a browser extension that analyzes URLs for security risks. This privacy policy explains what data we collect, how we use it, and your rights as a user.

## 🔍 What Data We Collect

### **URL Analysis Data**
- **What we collect:** URLs you visit for security analysis
- **When we collect:** When you navigate to websites or use the extension popup
- **How we collect:** Automatically when the extension is active
- **Why we collect:** To provide real-time security risk assessment

### **Technical Data**
- **What we collect:** Risk factors, analysis results, timestamps
- **Why we collect:** To improve our security algorithms and provide accurate risk assessments

### **User Feedback (Optional)**
- **What we collect:** Feedback submissions, comments, user reports
- **Why we collect:** To improve accuracy and reduce false positives

## 🚫 What We DO NOT Collect

- ❌ **Personal Information:** Name, email, phone number, address
- ❌ **Login Credentials:** Passwords, usernames, authentication tokens
- ❌ **Website Content:** Page text, images, videos, or form data
- ❌ **Browsing History:** Complete list of visited websites
- ❌ **Cookies or Session Data:** Website login sessions or tracking cookies
- ❌ **Payment Information:** Credit card numbers or financial data

## 🌐 How Your Data Is Used

### **Primary Purpose**
- **Security Analysis:** Assess URLs for phishing, malware, and other threats
- **Risk Scoring:** Calculate security risk levels using multiple factors
- **Real-time Protection:** Provide immediate security warnings

### **Secondary Purpose**
- **Algorithm Improvement:** Enhance our detection accuracy
- **Threat Intelligence:** Identify emerging security threats
- **Performance Optimization:** Improve response times and accuracy

## 📊 Data Storage & Retention

### **URL Analysis Data**
- **Stored Locally:** Risk assessments cached in your browser for 15 minutes
- **Sent to Backend:** URLs sent to our analysis server for security checks
- **Retention:** Analysis results cached temporarily for performance

### **User Feedback**
- **Stored:** In our database for algorithm improvement
- **Retention:** Up to 12 months for analysis purposes
- **Anonymized:** Personal identifiers removed before analysis

## 🔐 Data Security

### **Encryption**
- **In Transit:** HTTPS/TLS encryption for all API communications
- **At Rest:** Encrypted storage for sensitive data

### **Access Controls**
- **Limited Access:** Only authorized personnel can access data
- **Audit Logs:** All data access is logged and monitored
- **Security Reviews:** Regular security audits and penetration testing

## 🌍 Data Sharing

### **We DO NOT Sell Your Data**
- ❌ No data sold to third parties
- ❌ No data shared with advertisers
- ❌ No data used for marketing purposes

### **Limited Sharing**
- ✅ **Threat Intelligence:** Anonymized threat data shared with security researchers
- ✅ **Law Enforcement:** When required by valid legal process
- ✅ **Service Providers:** Limited data with trusted cloud providers

## 📍 Geographic Data

### **IP-Based Analysis**
- **What we use:** IP geolocation for geographic risk assessment
- **Why we use it:** Certain regions have higher threat concentrations
- **Your location:** Only country-level data, no precise location

## 🔧 Your Rights & Choices

### **Control Your Data**
- **Opt-out:** Disable extension at any time
- **Clear Data:** Clear extension storage through browser settings
- **Feedback Control:** Choose whether to submit feedback
- **Export Data:** Request a copy of your data (where applicable)

### **Browser Integration**
- **Permissions:** Extension requires specific browser permissions
- **Control:** You can revoke permissions at any time
- **Transparency:** All permissions are clearly disclosed
